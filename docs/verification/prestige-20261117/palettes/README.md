# Palettes MIR — proposition visuelle du 17 novembre 2026

Trois variantes de couleur ont été réalisées dans `dist/prestige-palettes.html`, avec la même photographie de maison et le logo SVG MIR existants. Il s’agit d’une proposition HTML de l’accueil, pas d’une modification du parcours métier.

- **Anthracite chaud / champagne / pierre claire**, recommandation retenue pour la refonte.
- Grège / bronze / blanc pierre, variante lumineuse.
- Brun graphite / cuivre doux / ivoire, variante enveloppante.

Les boutons permettent de comparer les trois propositions ou d’afficher chacune en grand. La photo, le titre « Votre projet commence ici. », l’accent italique, les deux entrées et l’avatar à droite des langues sont conservés. Aucune barre inférieure sur cet accueil. Le logo conserve sa couleur originale.

Captures réelles effectuées avec Chromium système via Playwright, après rendu HTML/CSS : `comparatif-pc.png`, les trois fichiers `*-pc.png` et `anthracite-mobile.png`. Inspection visuelle effectuée sur le comparatif et le grand écran anthracite; correction d’une flèche Unicode non disponible dans la police, remplacée par SVG. Contrôles : aucun débordement à 1440 ou 390 px, aucune erreur JavaScript, bascule des palettes opérationnelle. Les langues FR/EN de la proposition sont indicatives; elle ne constitue pas une recette bilingue.

Ressources : `assets/mir-home-hero-20261105.webp` et `assets/MIR-logo-officiel-original.svg`, inchangées. Pas de photo générée, de backend, de requête Supabase, d’envoi ni de paiement. Aucune publication.
